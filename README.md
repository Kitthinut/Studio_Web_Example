# ตู้เสื้อผ้า (Wardrobe) — Web App

แอปตู้เสื้อผ้าแบบเว็บ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ใช้ได้ทันทีบนมือถือผ่านเบราว์เซอร์

## ฟีเจอร์

1. **ตู้เสื้อผ้า** — เพิ่มเสื้อผ้าพร้อมข้อมูลชนิดผ้า สี ฯลฯ โดย
   - **ตรวจจับสีอัตโนมัติจากรูป**: อัปโหลดรูปแล้วแอปจะวิเคราะห์สีเด่นของภาพให้เอง (ประมวลผลในเบราว์เซอร์ล้วน ๆ ด้วย Canvas API) พร้อมบอก **% ความมั่นใจ** ว่าสีที่ตรวจพบครอบคลุมพื้นที่ภาพกี่เปอร์เซ็นต์ — แก้ไขเองได้ถ้าตรวจผิด
   - **สแกนป้ายผ้า**: ถ่ายรูปป้ายเสื้อ แอปอ่านตัวอักษรด้วย OCR ([Tesseract.js](https://github.com/naptha/tesseract.js) ทำงานในเบราว์เซอร์ ไม่ต้องมี API key) แล้วเดาชนิดผ้าให้ (เช่น cotton → ผ้าฝ้าย)
   - **สแกน Digital Product Passport (DPP)**: อ่าน QR code ด้วย [jsQR](https://github.com/cozmo/jsQR) แล้วดึงข้อมูลแบบยุโรป (ชื่อ แบรนด์ ส่วนผสมผ้า แหล่งผลิต วิธีดูแล คาร์บอนฟุตพรินท์ % รีไซเคิล) มากรอกให้อัตโนมัติทั้งหมด — **ข้อควรทราบ**: DPP ของสหภาพยุโรปสำหรับสิ่งทอ (ภายใต้กฎ ESPR) ยังไม่มีผลบังคับใช้จริง คาดว่า EU จะออกกฎเกณฑ์รายละเอียดช่วงครึ่งหลังปี 2027 เป็นต้นไป และยังไม่มีฐานข้อมูลกลางสาธารณะให้เว็บแอปแบบ static เรียกดูได้จริงในตอนนี้ ฟีเจอร์นี้จึงเป็น**การสาธิตการทำงาน**ด้วยฐานข้อมูลตัวอย่างในเครื่อง (`js/dpp-data.js`) — โครงสร้างการอ่าน QR ทำงานได้จริง เมื่อมีฐานข้อมูล DPP จริงให้เชื่อมต่อ (เช่นผ่าน API) ก็แก้แค่ฟังก์ชัน `resolveDPP()` ให้ไปเรียก API แทนได้เลย ระหว่างนี้ใช้ตัวเลือก "ลองตัวอย่าง DPP" กรอกข้อมูลตัวอย่างให้ดูผลลัพธ์ได้ทันที
   - **คาร์บอนฟุตพรินท์ / เนื้อผ้ารีไซเคิล**: กรอกเองได้ หรือปล่อยว่างให้แอปประมาณให้อัตโนมัติจากประเภทเสื้อผ้า+ชนิดผ้า (ตัวเลขเป็น**ค่าประมาณเพื่อการรับรู้ทั่วไป** ไม่ใช่ผลการประเมินวัฏจักรชีวิตผลิตภัณฑ์ (LCA) จริง — ถ้ามีตัวเลขจริงจากฉลากหรือ DPP ควรใช้ค่านั้นแทน)
2. **จับคู่ชุด** — เลือกเสื้อผ้าหนึ่งชิ้น แอปแนะนำชิ้นอื่นที่เข้ากัน โดยดูจากโทนสีและฤดู/โอกาสที่ตรงกัน กด **"ดูลุคเต็ม"** เพื่อเปิดป๊อปอัปแสดงชุดที่ประกอบเสร็จ (รวมชิ้นอื่น ๆ ที่เข้ากันเพิ่มให้อัตโนมัติ เช่น รองเท้า/เครื่องประดับ) พร้อม **พาเลตสี** ของทั้งลุค และคาร์บอนฟุตพรินท์รวม/% รีไซเคิลเฉลี่ยของทั้งชุด
3. **จุดบริจาค** — เลือกชิ้นที่จะทิ้ง แอปขอตำแหน่งปัจจุบัน (Geolocation API) แล้วแสดง**แผนที่แบบอินเทอร์แอกทีฟ** (Leaflet + OpenStreetMap ไม่ต้องมี API key เหมือน Google Maps) พร้อมหมุดจุดรับบริจาคที่รับผ้าชนิดนั้น เรียงตามระยะทาง คลิกหมุดดูรายละเอียดและลิงก์เปิดเส้นทางใน Google Maps ได้ พร้อมข้อความประเมินว่าการบริจาคแทนการทิ้งช่วยลดคาร์บอนได้ประมาณเท่าไร

ข้อมูลทั้งหมด (เสื้อผ้าในตู้) เก็บไว้ใน `localStorage` ของเบราว์เซอร์ผู้ใช้แต่ละคน — ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์ใด ๆ

## โครงสร้างไฟล์

```
wardrobe/
├── index.html          หน้าเว็บหลัก
├── manifest.json        สำหรับ "เพิ่มไปหน้าจอโฮม" บนมือถือ
├── css/style.css        สไตล์ทั้งหมด
├── js/app.js             ลอจิกหลัก (ตู้เสื้อผ้า, ตรวจจับสี, สแกนป้าย/DPP, จับคู่, แผนที่บริจาค)
├── js/dpp-data.js        ฐานข้อมูล DPP ตัวอย่าง + สูตรประมาณคาร์บอนฟุตพรินท์
└── js/donation-data.js   ข้อมูลจุดรับบริจาค (ตัวอย่าง — แก้ไข/แทนที่ได้)
```

## รันทดสอบในเครื่อง (VS Code)

ต้องเปิดผ่าน local server (ไม่ใช่เปิดไฟล์ตรง ๆ แบบ `file://`) เพราะกล้อง/ตำแหน่ง/OCR ต้องการ context ที่ปลอดภัย:

1. เปิดโฟลเดอร์ `wardrobe` ใน VS Code
2. ติดตั้ง extension **Live Server** (โดย Ritwick Dey) แล้วคลิกขวาที่ `index.html` → "Open with Live Server"
   - หรือถ้ามี Python: รัน `python3 -m http.server 5500` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:5500`
3. เปิดในเบราว์เซอร์มือถือ (หรือย่อหน้าต่างเบราว์เซอร์บนคอมให้แคบเพื่อดูมุมมองมือถือ)

> หมายเหตุ: ฟีเจอร์กล้อง (สแกนป้าย) และตำแหน่ง (จุดบริจาค) ต้องใช้งานผ่าน **HTTPS** หรือ `localhost` เท่านั้น — เบราว์เซอร์จะปฏิเสธถ้าเปิดผ่าน HTTP ธรรมดาบนโดเมนอื่น GitHub Pages ให้ HTTPS มาอัตโนมัติอยู่แล้ว จึงใช้งานได้ปกติหลัง deploy

## Deploy ขึ้น GitHub Pages

1. สร้าง repo ใหม่บน GitHub (เช่น `wardrobe-app`)
2. ใน terminal ที่โฟลเดอร์ `wardrobe`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: wardrobe app"
   git branch -M main
   git remote add origin https://github.com/<your-username>/wardrobe-app.git
   git push -u origin main
   ```
3. บน GitHub: ไปที่ repo → **Settings → Pages**
4. ใต้ "Build and deployment" เลือก **Source: Deploy from a branch**
5. เลือก branch `main` และ folder `/ (root)` แล้วกด **Save**
6. รอ 1–2 นาที เว็บจะขึ้นที่ `https://<your-username>.github.io/wardrobe-app/`

## ปรับแต่งต่อได้

- **จุดบริจาคจริง**: แก้ไขข้อมูลใน `js/donation-data.js` ใส่จุดรับบริจาคจริงในพื้นที่ของคุณ (ชื่อ, ที่อยู่, พิกัด lat/lng, ชนิดผ้าที่รับ) หรือจะดึงจาก API ภายนอกแทนก็ได้
- **กติกาจับคู่สี**: ปรับ logic ใน `colorScore()` และ `typesPair()` ใน `js/app.js` ให้ละเอียดขึ้น เช่น เพิ่ม color wheel จริงแทนการแบ่งเป็น 3 กลุ่ม
- **แม่นยำ OCR**: ถ้าต้องการอ่านป้ายภาษาไทยด้วย เปลี่ยน `Tesseract.recognize(dataUrl, "eng")` เป็น `"eng+tha"` ใน `js/app.js` (จะโหลดโมเดลภาษาไทยเพิ่ม ทำให้สแกนช้าลงเล็กน้อยในครั้งแรก)
- **บัญชีผู้ใช้/ซิงก์หลายเครื่อง**: ตอนนี้ข้อมูลเก็บในเครื่องเดียว (`localStorage`) ถ้าต้องการให้ใช้ข้ามอุปกรณ์ได้ ต้องเพิ่ม backend (เช่น Firebase, Supabase) มาแทนที่ `loadItems()`/`saveItems()` ใน `js/app.js`
- **เชื่อมต่อ DPP จริง**: เมื่อมีฐานข้อมูล/API ของ DPP จริงให้ใช้งานแล้ว แก้ฟังก์ชัน `resolveDPP()` ใน `js/dpp-data.js` ให้ยิง request ไปที่ API นั้นแทนการค้นใน `MOCK_DPP_REGISTRY`
- **แผนที่**: ใช้ Leaflet + OpenStreetMap (ฟรี ไม่ต้องมี API key) ถ้าต้องการหน้าตาแบบ Google Maps เป๊ะ ๆ พร้อม Street View ก็เปลี่ยนไปใช้ Google Maps JavaScript API แทนได้ (ต้องสมัคร API key และอาจมีค่าใช้จ่ายเมื่อเรียกเกินโควตาฟรี)
